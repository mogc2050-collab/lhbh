# Medieval Life | ممالك الحياة

**A playable, fully offline Arabic Flutter economy + life simulation game.**

See [README_AR.md](README_AR.md) for full Arabic setup instructions, features, limitations, and how to build a downloadable Android APK using **GitHub Actions manually only**.

## Build on GitHub

- Upload the **extracted repository contents** (`pubspec.yaml`, `lib/`, `test/`, `.github/`) to your GitHub repository.
- Actions → **Build Android APK - Manual Only** → **Run workflow**.
- Download `app-release.apk` from the successful job's **Artifacts**.
- No push/PR/schedule triggers exist. Android scaffolding is generated by the workflow, so no local SDK installation is required.

The actual game uses original vector 2D isometric rendering. Art concepts in `design_reference/` are non-interactive design references only. This is a feature-rich starting game, not a 3D production clone of a commercial title.
