# Mamlakat Al-Hayat - Complete Rebuild v3

Fully offline Arabic medieval city-building and economy simulation for Android, written in Flutter.

This is a **new gameplay engine**, not the previous screenshot-overlay UI: 64x64 isometric interactive world, independent 3D-looking 2.5D building sprites, clickable NPC characters, four independent cities and commodity markets, 20 building classes, 17 goods, input/output production chains, hunger/thirst/energy/health, paid jobs, travel risk, caravans, deliveries, loans, taxes, and autosave.

Design direction: detailed wood-and-gold medieval UI from the supplied concept art. Visual truth: procedurally painted 2.5D gameplay, not photorealistic 3D. No full-screen concept screenshots are rendered in the playable app.

Build: workflow_dispatch ONLY, manually run the GitHub Actions Build APK workflow. Android Studio is not needed locally.

See README_AR.md for the full Arabic guide.
