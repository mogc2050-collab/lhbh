# Mamlakat Al Hayat – Flutter Offline Game (Fix for APK installation)

This is the updated installability-focused package for the original game.

- **Only manual GitHub Actions trigger**: `workflow_dispatch`.
- **Direct APK instead of ZIP**: `actions/upload-artifact@v7` with `archive: false`.
- **Stable, publicly known TEST-ONLY signing key**, with optional secret-driven private release signing.
- **Validation**: APK ZIP integrity, `apksigner`, `zipalign`, `aapt` and Flutter ARM runtime checks.
- **Optional Android emulator install & launch smoke test**, enabled by default.
- Flutter scaffolding generated by `flutter create --platforms=android` in CI.

This repository is a prototype and not suitable for production signing as-is. See `README_AR.md` and `SIGNING_AND_INSTALL.md`.

## World and economy update 1.1

Expanded 32×32 isometric world; four cities with distinct regional stock, prices and money; travel costs, food/water consumption, travel risk, loans with daily compound interest, taxation vs reputation, and loss-making or profitable caravans. Added original offline sound effects and ambience. **The rendering remains 2D isometric, not real-time 3D.** Manual-only Actions workflow remains unchanged. See README_AR.md.
