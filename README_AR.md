# ممالك الحياة • الإصدار 3.0 | إعادة بناء من الصفر

## إيه اللي اتغير؟
دي **لعبة جديدة بكود جديد بالكامل**. مفيش استيراد لمحرك الاقتصاد القديم ولا استخدام للصور المركبة كشاشات ثابتة.

- خريطة إيزومترية 64×64، فيها 4 مدن، طرق، أنهار، غابات، أرض زراعية، ومبانٍ مستقلة قابلة للنقر
- كل مبنى ليه إحداثيات وكائن مستقل وتكلفة بناء وترقية وبيع وإنتاج ومخزن وعمال
- **20 فئة مبانٍ** تشمل منشرة، مطحنة، مخبز، محجر، منجم، حدادة، مزارع، حظائر، نسيج، نجارة، بيوت، سوق، مخزن، نزل، إسطبل وعيادة
- **17 نوع موارد** بسلاسل إنتاج: قمح ← دقيق ← خبز، خشب ← ألواح ← أثاث، حجر ← طوب، حديد ← أدوات، صوف ← قماش
- 4 أسواق مستقلة بأسعار تعتمد على المخزون والتخصص والموسم؛ شراء وبيع حقيقي بدون مكسب مضمون
- سكان وعمال وإيجارات وصيانة وضرائب وديون وفوائد ورضا عام
- الشخصية تعيش وتحتاج طعامًا وماءً ونومًا ونظافة وصحة، وتقدر تعمل وتحتطب وتتفاعل مع الشخصيات
- سفر برسوم ومؤن ووقت ومخاطرة، عقود تسليم، قوافل استثمارية ممكن تربح أو تخسر
- أسماء وشخصيات NPC منفصلة في المدن (تجار، بنّائين، مزارعين، رحالة) مع تفاعل مباشر
- مؤثرات صوتية مختلفة مُولّدة محليًا، وحفظ محلي أوفلاين بالكامل

## الرسم والجودة الفنية
المرجع البصري هو صور اللعبة الأربع اللي اتقدمت في المحادثة: خشب/ذهب، بيوت وأكشاك وأسواق وقلعة وزراعة وأيقونات. لكن للتوضيح المهني:
**دي رسوم 2.5D إيزومترية مرسومة بالكود وليست بيئة 3D سينمائية بنفس فوتوريالية صور الذكاء الاصطناعي.**
كل مبنى وشخصية قابلين للتفاعل كعناصر مستقلة، وليس جزءًا من لقطة شاشة ثابتة. الوصول لمستوى الصور حرفيًا يتطلب أصول 3D مصممة ومنفذة ومُجهزة بمحرّك ثلاثي الأبعاد وتحريك ومواد وإضاءة. النسخة الحالية لا تدّعي ذلك.

## الملفات
- `lib/kingdom/catalog.dart`: الموارد والمدن والمباني والشخصيات والعقود وتضاريس الخريطة
- `lib/kingdom/engine.dart`: المحاكاة الاقتصادية والحياة والتجارة والسفر والحفظ الجديد
- `lib/kingdom/audio.dart`: أصوات أوفلاين منفصلة
- `lib/visual/world_painter.dart`: رسم كائنات العالم كلّها مستقلّة
- `lib/visual/skin.dart`: مكونات واجهة الذهب والخشب وتفاصيل المباني
- `lib/visual/game_screen.dart`: واجهات اللعب والاقتصاد والسوق والعقارات والشخصية

## حفظ جديد
المفتاح `mamlakat_life_rebuilt_v3` جديد. ما فيش سحب أو استعادة تلقائية لتقدم النسخة القديمة؛ تقدر تحتفظ ببيانات النسخة السابقة في جهازك لكن اللعبة الجديدة تبدأ اقتصادها من البداية.

## بناء APK من غير برامج
المستودع يحتفظ بـ `.github/workflows/build-apk.yml` وفيه `workflow_dispatch` **فقط**.
1. افتح GitHub > Actions > Build APK Direct (Manual Only).
2. اضغط Run workflow على فرع main.
3. راجع نتائج `flutter test` والبناء وفحص التثبيت، ثم حمّل APK.

الـAPK غير مُختبر في بيئة التأليف، لأن Flutter SDK غير متاح هنا. GitHub Actions هو اختبار التجميع والتشغيل الحقيقي.

ملاحظة أمنية: مفتاح التوقيع التجريبي المرفق في المستودع **عام وغير مناسب للنشر الرسمي**. استخدم مفتاحًا خاصًا عبر GitHub Secrets قبل النشر.
