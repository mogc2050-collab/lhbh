# ممالك الحياة | نسخة البناء المصححة (APK مباشر)

**لعبة Flutter عربية أوفلاين** تضم البناء والتجارة والإنتاج واحتياجات الشخصية والحفظ المحلي.

## الفرق عن النسخة السابقة

1. **APK مباشر من GitHub Actions**: نستخدم `actions/upload-artifact@v7` مع `archive: false`. الملف يظهر باسم `Mamlakat-Al-Hayat.apk` ولا يُنزّل في ZIP (على GitHub.com المدعوم).
2. **توقيع ثابت للتجربة**: أضفنا مفتاحًا تجريبيًا ثابتًا، فلا يتغيّر توقيع النسخة تلقائيًا بين مرات تشغيل GitHub. المفتاح مخصّص للاختبار فقط، وغير آمن للنشر العام. راجع `SIGNING_AND_INSTALL.md`.
3. **فحص APK**: نفحص سلامة الأرشيف الداخلي للحزمة، وشهادة التوقيع، و`zipalign`، وبيانات الـ Manifest، ومعمارية المكتبات.
4. **اختبار تثبيت وتشغيل فعلي**: GitHub Actions يمكنه تشغيل محاكي Android API 35، وتثبيت APK عليه وإطلاق التطبيق للتأكد من بقائه مفتوحًا.
5. **تحديث رقم النسخة**: رقم البناء يزيد تلقائيًا عند كل تشغيل جديد لتجنب أخطاء تخفيض إصدار التطبيق.
6. **يدوي 100%**: لا يوجد `push` أو `pull_request` أو `schedule` في ملف البناء، بل `workflow_dispatch` فقط.

## طريقة الاستخدام من متصفح كمبيوتر الشركة

1. فك الضغط عن ZIP المرفق في المحادثة.
2. افتح GitHub ثم مستودع اللعبة. ارفع **كل محتويات** مجلد `medieval_life` إلى جذر المستودع (بما فيها مجلد `.github` المخفي و`signing` و`scripts`). احذف أو استبدل الملفات القديمة عند تعارضها.
3. تأكد أن `pubspec.yaml` في الجذر وأن `.github/workflows/build-apk.yml` موجود في موقعه الصحيح.
4. اختر **Actions → Build APK Direct (Manual Only) → Run workflow**.
5. اترك خيار `test_installation_on_emulator` مفعّلًا في أول مرة لمراجعة قابلية التثبيت والتشغيل على محاكي.
6. بعد البناء افتح صفحة تشغيل الـWorkflow الحالية. من **Artifacts** اضغط ملف **`Mamlakat-Al-Hayat.apk`** لينزل مباشرةً.
7. افتح APK على الهاتف. اسم اللعبة على الجهاز «ممالك الحياة».

> مهم: لا ترفع ZIP نفسه كملف داخل المستودع. ارفع محتويات المجلد، وخصوصًا ملف الـWorkflow.

## لو ظهر Can't install app على الهاتف

- افتح خطوات البناء، خصوصًا **Verify actual APK signature** و**Install APK and open the game**. أحيانًا ينجح البناء لكن يفشل التثبيت، والتقرير يساعدنا نحدد السبب.
- تأكد أن الهاتف متوافق مع `sdkVersion` ومع المعمارية المذكورة في خطوة التحقق.
- قد تكون هناك نسخة من اللعبة مثبتة بتوقيع مختلف. **قبل إزالتها احفظ بياناتك المهمة** لأن إزالة التطبيق قد تحذف الحفظ المحلي.
- إن كانت المشكلة خاصة بجهازك، فخطأ «Can't install app» وحده لا يحدد السبب، وقد نحتاج موديل الهاتف، نسخة Android، ولقطة من الرسالة الكاملة أو رمز ADB إن توفر.

## ما الذي لم يتغيّر؟

اللعبة نفسها لا تزال النسخة الأولية ثنائية الأبعاد ذات عالم إيزومتري، وليست نسخة ثلاثية الأبعاد مطابقة للصور المرجعية. هذا التحديث لإصلاح وتدقيق **حزمة Android وطريقة تنزيلها وتوقيعها** وليس إضافة مراحل لعب جديدة.

## تحذير أمان

المفتاح داخل `signing/` عام تجريبي حتى لو المستودع Private. لا تستخدمه في إصدار حقيقي. لتحويل المشروع للنشر العام استخدم شهادة توقيع خاصة محفوظة في GitHub Secrets حسب `SIGNING_AND_INSTALL.md`.

## تحديث العالم والاقتصاد 1.1 (19 نوفمبر 2026)

تم توسيع العالم الإيزومتري من 12×12 إلى **32×32 = 1024 بلاطة**. الصورة لا تمثل محرك 3D حقيقيًا: هذه نسخة Flutter ذات رسم إيزومتري ثنائي الأبعاد، وللوصول إلى رسومات 3D عالية الجودة لا بد من مشروع 3D منفصل مع نماذج ثلاثية الأبعاد ورسوم متحركة وإضاءة ومقاييس أداء.

### المدن والسفر
- **مدينة الوادي** مركز أعمالك الأساسي.
- **مدينة الغابة** مصدر للأخشاب بتكلفة منخفضة، وغذاؤها أغلى.
- **مدينة الميناء** غنية بالغذاء وتحتاج مواد البناء.
- **مدينة الجبال** وفيرة الحجر، وتحتاج خشبًا وأدوات.

لكل مدينة مخزون تاجر وسيولة مختلفة، وتتغير الأسعار وفق الوفرة والطلب والموسم. السفر يستهلك ذهبًا وخبزًا وماء وطاقة ووقتًا، وقد تتعرض القافلة للخسارة. من زر **سفر** في شاشة اللعب يمكنك زيارة أي مدينة، والمقارنة بين أسعار الموارد، وإرسال قوافل استثمارية قد تربح أو تخسر.

### قرارات ذات عواقب
من **اقتصاد** يمكنك خفض الضرائب أو رفعها، والحصول على قرض أو سداده. الضرائب المرتفعة تزيد الإيرادات لكنها تخفض رضا السكان. القروض لها **فائدة 2% لكل يوم لعبة**. استثمارات القوافل غير مضمونة وقد تحقق خسارة.

### أصوات وأجواء محلية
أضيفت 18 نغمة ومؤثرًا صوتيًا مختلفة للشراء والبيع والمشي والبناء والترقية والعمل والغذاء والسفر وغيرها، مع صوت بيئة متكرر. يتم **توليد موجات WAV محليًا داخل التطبيق** بدون ملفات موسيقية خارجية أو اتصال بالشبكة، ويمكن إيقاف الصوت من الإعدادات.

### البناء من GitHub
ملف `.github/workflows/build-apk.yml` يحتفظ بـ`workflow_dispatch` فقط؛ لم تتم إضافة `push` أو `pull_request` ولا يحدث أي بناء تلقائي. شغّله من Actions عندما تريد. هذا التحديث يضيف مكتبة `audioplayers` ويولّد أصوات WAV داخل الذاكرة.

### ما لم يُنفذ بعد
هذا تحديث قابل للعب لمحرك الاقتصاد والعالم والأصوات وليس لعبة حياة 3D فوتوريالية؛ لا يوجد حاليًا نموذج ثلاثي الأبعاد حقيقي أو نظام مرور ومواطنين واقعي مستقلين أو سفر بصري مفتوح بلا تحميل. الانتقال الفني الحقيقي المقترح: **Godot 4 ثلاثي الأبعاد** مع الإبقاء على تصميم الاقتصاد والحفظ والترحيل المدروس. لا ينبغي اعتبار الصور المرجعية لقطات من لعبة مكتملة.
